# 旅行行程编排软件

四人软件工程课程项目，三周实现景点浏览、每日编排、时间检查、预算和路线示意。当前为需求评审与开发准备，技术栈待团队确认。

## 目录

frontend 为页面与交互，backend 为接口与计算，data 为演示数据，tests 为测试。
docs/requirements 保存需求基线，docs/design 保存设计，docs/planning 保存任务与风险，docs/process 保存真实过程记录。

## 第一周演示

创建三日旅行 → 找景点 → 加入第一天 → 调整顺序 → 保存 → 刷新恢复。
