## 项目范围

目标用户为规划个人短途旅行的使用者。输入为旅行日期、景点、停留和费用，输出为可保存的每日计划、时间检查、预算及路线示意。首版限定单城市、预置数据和本地Web运行。

| 边界 | 第一轮实际交付 | 第二三轮计划 |
|---|---|---|
| 旅行 | 固定三日创建、列表和打开 | 2–5天选择、修改、删除 |
| 景点 | 四个演示景点 | 详情、搜索、分类与扩大数据 |
| 编排 | 日期切换、按钮排序删除 | 跨天、停留与每日时间编辑 |
| 计算展示 | 可保存原始输入 | 时间预算、交通与路线联动 |
| 数据可靠性 | 保存、加载、revision检查 | 完整嵌套校验、离开保护与响应隔离 |

在线支付、实时交通、多人协作和自动路线优化属于后续候选范围。新增功能先记录影响和取舍。
