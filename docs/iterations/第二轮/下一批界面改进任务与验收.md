# 第二轮下一批界面改进任务与验收

制定日期2026-11-27，依据阶段评审。状态为实施准备。以下尺寸是下一批目标，不代表已测结果。

## 任务顺序

1. 杨子游与李乾坤确定两种风格的色彩、功能层级与布局，优先创建和编排操作。
2. 李乾坤落实字号、按钮与布局，确保主题切换保留草案。
3. 杨子游整理湖泊、山林、城市三类场景的四季图片，记录来源和标签。
4. 张博涵配合元数据与本地资源配置，李乾坤接入手动切换和图片失败保护。
5. 张紫萱测量前后布局，验证主题季节切换、弱网失败、手机操作及原流程回归。

## 验收标准

| 编号 | 条件 |
|---|---|
| UX-T01 | 在1440×900视口，创建区起点目标不晚于360px，名称日期与创建按钮可在首屏操作 |
| UX-T02 | 编排主操作文字至少14px，按钮点击区域至少40px高，移动端关键按钮至少44px |
| UX-T03 | 两种风格可切换，日期选中态、文本与保存按钮清楚，焦点状态可辨 |
| UX-T04 | 三类场景均可选择春夏秋冬，共12个明确标注的示意组合 |
| UX-T05 | 切换风格、场景、季节不修改旅行id、条目顺序、费用或草案状态 |
| UX-T06 | 图片加载失败显示替代内容，切换及返回可用，不重复无限请求失败图片 |
| UX-T07 | 390px视口无横向溢出，编排优先可达，景点详情及保存可操作 |
| UX-T08 | 图片按当前选择加载，本地资源有来源，网络请求不预加载全部四季图片 |
| UX-T09 | 回归搜索分类、添加排序、保存重开、未保存保护及版本冲突 |

示意图片不标成合成景点的真实历史四季照片。12组合先保证可核查素材与显示，再按实际体验优化。验收后更新测量和问题关闭证据。
