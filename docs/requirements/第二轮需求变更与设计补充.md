# 第二轮需求变更与设计补充

编号CHG-02，日期2026-11-27。原需求规格说明书V1.2作为历史基线，本补充与当前故事、设计共同描述现行范围。变更依据为已确认的小组界面反馈及阶段评审，下批实现由对应验收验证。

## 已实现状态回写

搜索分类详情和界面改进已通过阶段验收。保存保护、请求归属、嵌套模型、费用校验与404/409已有自动回归。跨天、完整时间预算和路线图继续按后续任务跟踪。

## 新增功能需求

FR-VIS-01支持两种独立视觉风格，切换后保留当前旅行及草案。
FR-VIS-02支持湖泊、山林、城市三类风景的春夏秋冬，共12个明确示意组合。默认手动切换。
FR-VIS-03图片失败显示替代内容，页面操作可继续，失败资源不无限重试。
FR-UX-01创建与编排入口优先，日期选中、保存及错误反馈清楚。
NFR-UX-02在1440×900视口，创建区起点目标≤360px；主操作文字≥14px、点击区高≥40px，手机关键操作≥44px；390px无横向溢出。
NFR-RES-01按当前选择加载图片，素材来源可查，图片标签明确为演示示意。

## 数据与交互设计

SceneAsset保存assetId、sceneId、season、src、alt和sourceUrl。ThemePreference保存styleId、sceneId和season。方案使用前端静态配置，默认不改旅行数据库和业务接口。浏览偏好仅作为视觉状态，和Trip分开管理。

选择风格修改界面样式，选择场景季节更新背景。加载期间保留可用画面，错误时展示稳定占位。切换过程不触发行程重排、费用修改或自动丢弃草案。
