# 流程章程修订验收清单

删除固定会议钟点与星期，按事件描述执行。第一轮两天日期与后续迭代边界保留；业务时间单位不变。

## 流程记录覆盖

计划、站会、调查联调、评审和回顾均有对应归档，记录性质及证据范围见敏捷规程的对应表。
