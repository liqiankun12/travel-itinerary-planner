# 第一轮运行与验证

## 启动后端

在项目根目录执行：

~~~powershell
cd backend
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
~~~

## 启动前端

另开一个终端：

~~~powershell
cd frontend
npm install
npm run dev
~~~

打开终端显示的本地地址，通常为http://127.0.0.1:5173。
后端接口文档为http://127.0.0.1:8000/docs。

## 人工验收

1. 创建一个名称明确的三日旅行。
2. 第一日加入两个景点，再重复加入其中一个，应提示重复。
3. 点击上移下移，记录当前顺序，删除其中一个再添加。
4. 点击保存，看到已保存后刷新，重新打开该旅行。
5. 检查三天、景点和顺序一致。
6. 停止后端后保存，应显示失败并保留编辑。恢复后重试。
7. 两个窗口打开同一旅行，先后保存，后保存的旧版本应显示冲突。

当前使用按钮排序，跨天、时间与预算编辑以及完整路线仍为后续迭代范围。人工验收实际结果由成员填写。
